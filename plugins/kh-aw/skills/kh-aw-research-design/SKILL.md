# KH_Aw Research and Every-Page Design

## Research gate

Replace the dynamic research-plan entries from current requirements and analysis. Search is discovery only. Save the actual destination body and extracted text with URL, HTTP status, source type, project-fit reason, license/rights note, and SHA-256 through `fetch-source` or `register-source`.

Search-result pages, snippets, titles, empty JSON shells, CAPTCHA, login/access-denied pages, and URLs without physical body files fail. Native `/goal`, `/agents`, `/search`, and `/artifact` evidence is required. The body registry is additional physical research evidence and cannot replace a required slash invocation.

## Design gate

The page inventory must exactly match all analyzed/required pages. Before implementation, create for every page:

- a unique HTML/SVG mockup;
- a unique PNG;
- all required region, field, logic, feature, and state IDs physically embedded;
- page-specific layout, typography, color, imagery, icon, motion, conversion, accessibility, and performance rationale tied to current research;
- image slots with purpose, aspect ratio, and source/generation strategy;
- motion storyboard with trigger, from/to, duration, easing, purpose, and reduced-motion behavior;
- one all-page comparison board with hashes.

Manual concept/color/template pickers, fixed KH_Aw palettes, hardcoded future-project designs, representative samples, and one mockup reused for multiple pages fail. `advance --stage design` invokes physical rendering when needed and the gate compares files and hashes.

## Mandatory multi-agent execution

This skill participates in the KH_Aw stage gate. Before the stage can pass, run `prepare-agents`, execute every planned assignment as an independent Codex subagent (`/agents`) or independent Codex task, register physical outputs with `record-subagent`, perform cross-review, and register the stage lead aggregation with `aggregate-agents`. The canonical count is dynamically calculated from 2 to 60 and cannot be weakened by editing JSON or by a prose claim.
