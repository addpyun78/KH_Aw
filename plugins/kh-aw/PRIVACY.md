# KH_Aw Privacy Policy

KH_Aw is a skill-only Codex plugin. It does not include an external app, hosted service, analytics SDK, advertising SDK, or publisher-operated data server.

KH_Aw creates evidence and workflow files inside the repository or the explicitly selected output workspace. A supplied analysis folder is backed up and hashed for source-protection checks. The plugin does not intentionally transmit project data to the publisher.

Web research performed by Codex or the included optional fetch command contacts the exact public URLs chosen for the current project. Those websites receive ordinary HTTP request information according to their own policies. Do not submit secrets, private repositories, customer data, credentials, cookies, browser profiles, or regulated personal data as public research queries.

Public release checks exclude browser profiles, login/cookie databases, runtime data, logs, caches, dependency folders, backups, and secrets. Users remain responsible for repository permissions, source licenses, image rights, privacy notices, and compliance obligations of the products they build.
