# 설치, 업데이트, 제거

## 설치

Codex의 플러그인 관리 화면 또는 `/plugins`에서 GitHub 마켓플레이스를 추가하고
`kh-aw`를 설치합니다. 설치 후 새 작업을 열어야 새 스킬이 보입니다.

## 업데이트

1. 진행 중인 작업은 `status`로 상태를 확인합니다.
2. 새 버전을 플러그인 관리 기능으로 업데이트합니다.
3. 새 Codex 작업을 엽니다.
4. `installation-status`로 활성 후보와 중복 캐시를 확인합니다.
5. `doctor`를 실행합니다.
6. 기존 프로젝트는 `resume`을 사용합니다. 저장된 프로젝트 runtime이 기존
   작업의 엔진 버전을 보호합니다.

## 제거

Codex 플러그인 관리 기능에서 `kh-aw`를 제거합니다. 프로젝트의 `.kh_aw` 폴더는
작업 기록이므로 자동 삭제하지 않습니다. 기록까지 지우려면 먼저 필요한
release receipt와 로그를 별도 보관한 뒤 사용자가 직접 결정해야 합니다.

## 버전 확인

패키지 기준 버전은 `VERSION_LEDGER.json`과
`plugins/kh-aw/.codex-plugin/plugin.json`에서 확인합니다. ZIP 이름, 내부 버전,
캐시 버전이 서로 다르면 설치를 진행하지 않습니다.
