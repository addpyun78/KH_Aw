# Public Plugin Failure Patterns

1. Overlapping skills compete for the same request.
2. Large `SKILL.md` files defeat progressive disclosure.
3. Relative script paths assume a source checkout and fail from versioned caches.
4. Undeclared surface-specific slash commands become hard dependencies.
5. Hook-only enforcement fails where trust or hook support is unavailable.
6. Retry loops repeat the same strategy without issue classification.
7. Cache presence is mistaken for active installation.
8. Tests validate synthetic receipts but not the actual Codex install path.
