# Public Plugin Success Patterns

1. Small public entrypoints with progressive disclosure.
2. Deterministic scripts for operations that should not depend on prose.
3. References separated from invocation metadata.
4. Explicit agents for independently reviewable work.
5. Tests around hooks, scripts, and packaging.
6. MCP/app declarations only where a real external capability exists.
7. Installation metadata that matches the platform's actual directory model.
8. Evidence retained as files and receipts rather than completion claims.
